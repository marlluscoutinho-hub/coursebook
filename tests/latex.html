Casos de teste de LaTeX

1. Display longo com \text (definição de Θ — Cap. 3 do CLRS)

[ DEFINIÇÃO FORMAL ] $$\Theta(g(n)) = \{ f(n) : \text{existem constantes positivas } c_1, c_2 \text{ e } n_0 \text{ tais que } 0 \le c_1 g(n) \le f(n) \le c_2 g(n) \text{ para todo } n \ge n_0 \}.$$

2. Display muito largo sem \text

$$T(n) = a_0 + a_1 n + a_2 n^2 + a_3 n^3 + a_4 n^4 + a_5 n^5 + a_6 n^6 + a_7 n^7 + a_8 n^8 + a_9 n^9 + a_{10} n^{10}$$

3. Inline longo em parágrafo (o último \text é limitação conhecida: corrigir no conteúdo, virando display)

Considere $f(n) = \sum_{i=0}^{n} \binom{n}{i} x^i y^{n-i} = (x+y)^n$ e também $\lg(n!) = \Theta(n \lg n)$ e ainda $\text{uma expressão com texto muito longo dentro de um inline que não deveria vazar}$ no fim.

4. Dentro de lista aninhada

  • Exemplo: provando que $$c_1 n^2 \le \tfrac{1}{2}n^2 - 3n \le c_2 n^2 \quad \text{para todo } n \ge n_0 \text{ com } n_0 = 7 \text{ e } c_1 = \tfrac{1}{14}, c_2 = \tfrac{1}{2}.$$

5. Dentro de callout de invariante

[ INVARIANTE ]

No início de cada iteração, $A[1..j-1]$ contém os elementos originais de $A[1..j-1]$ em ordem não decrescente, e vale $\sum_{k=1}^{j-1} A[k] = \sum_{k=1}^{j-1} A_{\text{orig}}[k]$.
