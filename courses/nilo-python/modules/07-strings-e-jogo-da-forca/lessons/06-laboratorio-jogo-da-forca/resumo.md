# Resumo da Unidade: Laboratório de Strings e Jogo da Forca

### Síntese Prática

1. **Simetria dos Índices:** Todo caractere em uma string possui índice positivo $i$ e negativo correspondente $i - \text{len}(S)$, facilitando a extração a partir dos extremos.
2. **Reatividade Textual:** Métodos de string não modificam a string original na memória; produzem cópias transformadas, preservando a integridade das variáveis originais.
3. **Resiliência do Game Loop:** O controle estrito de letras previamente testadas impede que repetições involuntárias punam o usuário duas vezes.
4. **Renderização Incremental:** A evolução gráfica da forca em estágios discretos ilustra a correspondência direta entre contadores numéricos de erro e matrizes visuais de saída.
