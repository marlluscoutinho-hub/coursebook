# Resumo da Unidade: Validação Léxica e Cláusulas de Guarda

### Pontos Essenciais

1. **Métodos de Predicado:** `isalnum()`, `isalpha()` e `isdigit()` inspecionam o conteúdo dos caracteres de uma string sem gerar exceções.
2. **Operador Ternário:** A sintaxe `v_true if cond else v_false` avalia uma expressão condicional em uma única linha legível.
3. **Instrução `continue`:** Descarta o restante do bloco de código da iteração corrente e avança imediatamente para o teste de repetição do laço.
4. **Cláusulas de Guarda:** A combinação de `continue` com verificações de entrada impede erros antes que o algoritmo principal seja executado.
