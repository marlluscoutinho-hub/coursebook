O padrão de projeto mais elementar e universal da programação algorítmica é o **contador**. Seja para numerar itens de uma lista, disparar uma contagem regressiva para o lançamento de um foguete espacial ou calcular a tabuada completa de um número, o padrão contador estrutura o ritmo de execução dos programas. Nesta aula, exploramos suas variações progressivas, regressivas e com passos customizados.
