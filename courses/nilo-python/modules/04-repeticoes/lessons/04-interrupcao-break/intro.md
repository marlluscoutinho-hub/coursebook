Em muitos problemas práticos, não sabemos com antecedência quantas iterações serão necessárias: um caixa de supermercado passa itens até que o cliente diga que terminou; um leitor de dados processa registros até encontrar o caractere de fim de arquivo. Nesses cenários, a condição de parada surge no meio do laço. Para permitir saídas imediatas e limpas, o Python disponibiliza a instrução `break`.
