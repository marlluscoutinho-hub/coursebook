No desenvolvimento de software profissional, os dados raramente se apresentam como variáveis soltas ou tabelas planas simples. Sistemas reais de inventário, comércio eletrônico e folha de pagamento combinam listas e dicionários para modelar relacionamentos complexos. Nesta aula, exploramos dicionários onde os valores são listas ou sub-dicionários, criando mini-bancos de dados relacionais diretamente na memória RAM.
