Problemas complexos do mundo corporativo raramente se resolvem com uma única decisão binária. Frequentemente, a necessidade de tomar uma segunda decisão depende inteiramente do resultado da primeira — como verificar se uma conta bancária está ativa para somente então checar se o saldo é suficiente. Nesta aula, exploramos o aninhamento de estruturas condicionais (`if` dentro de `if`) e o rigor necessário no controle dos níveis de indentação.
