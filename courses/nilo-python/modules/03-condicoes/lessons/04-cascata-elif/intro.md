Quando um sistema precisa escolher entre quatro, cinco ou dez opções mutuamente exclusivas — como selecionar categorias de produtos, tipos de instalação elétrica ou operações matemáticas em uma calculadora —, encadear sucessivos blocos `else: if:` empurra o código perigosamente para a direita da tela. Para resolver essa sobrecarga visual com elegância e clareza, o Python oferece a palavra-chave reservada `elif` (abreviação de *else if*). Nesta aula, você dominará sua aplicação.
